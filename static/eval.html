Evaluate a tax chatbot's answers

This tool scores chatbot answers on whether they are backed by documents, on topic, and correct. It works for Sagot AI (run live) and for any other chatbot, such as BIR's REVIE, as long as you have its answer.

The four data points

Every evaluation is built from the same four pieces. Some come from you, some from the chatbot. The example is question A2 from the thesis dataset.

translate

Optional fifth field: expected language. Mark each question as english or taglish (Filipino counts as taglish). It is only used for the three language-trigger scores, which test whether Sagot AI correctly notices a Taglish question.

What each score means

All scores run from 0 to 1, where higher is better, except the False Positive Rate, where lower is better. Answers are graded by an independent judge model that is not part of Sagot AI, so the system never grades itself.

info Labels such as “Mostly supported” are a reading aid chosen for this tool, not official RAGAS cut-offs. A score that cannot be computed is shown as — with the reason, never as 0.

Reading the statistics

When two sets of answers are compared (English vs Taglish, or Sagot AI vs REVIE), the tool runs the tests from the SOP.

Which test

Shapiro–Wilk first checks whether the score differences look normally distributed. If yes, a paired t-test is used; if not, the Wilcoxon signed-rank test.

p-value

Below 0.05 means the difference is statistically significant: unlikely to be chance. Above 0.05 means no significant difference was found. That is not proof the two are equal, especially with few questions.

Effect size

How big the difference is. For the t-test, Cohen's d: negligible < 0.2, small 0.2–0.5, medium 0.5–0.8, large > 0.8. For Wilcoxon, rank-biserial r: negligible < 0.1, small 0.1–0.3, medium 0.3–0.5, large ≥ 0.5 (the SOP: “r above 0.5 is large”). Always report it with the p-value.
